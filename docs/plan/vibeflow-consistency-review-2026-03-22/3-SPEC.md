# Spec

## Acceptance Criteria

- Inventory of mirrored files is complete.
- All drift between `.apm` and `.github` is classified.
- Agent frontmatter and tool lists are checked for stale or invalid entries.
- Docs are checked against the current orchestration behavior.
- Version and manifest references are reviewed for consistency.

## Output Format

- Findings listed by severity.
- Each finding includes evidence, impact, and proposed fix.
- Any required mirroring is explicitly called out.
